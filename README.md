### What I Believe

**AI 的根本瓶颈不是智力，是基础设施。**  
用了一百次还和第一次一样的 AI，不是助手，是陌生人。

**Agent 当人来培养，不当工具来配置。**  
一个资深工程师值钱不是因为打字快 — 是因为他知道项目的历史、团队的规矩、哪些路走不通。把这条成长曲线编码成基础设施，AI 就不再是 day-one 新人。

**Coding as Black Box.**  
一句需求到交付，中间不需要对齐任何人。测试验证行为，对抗性审查抓盲区，质量收敛循环迭代到通过为止。

**Content as Black Box.**  
一句话到可发布内容，不需要人修间距、对齐、字体。同一套模式：生成 → 验证 → 修 → 再验 → 直到所有 gate 同时通过。

**越用越聪明，不是越用越多。**  
犯过的错在结构上不可能再犯。每次交付让下一次更好。第 100 次使用读到的上下文比第 1 次丰富 100 倍。
